# 0003 通过模拟键盘输入密码解锁

- 状态：已接受
- 日期：2026-09-23

## 背景

macOS 没有公开 API 可以在锁屏状态下解锁。可选方案：

| 方案 | 评价 |
|---|---|
| **CGEvent 模拟键盘输入密码** | 原型在 macOS 26.5 上验证可行（unicode 模式），实现简单 |
| 虚拟智能卡（CryptoTokenKit） | 系统级支持，但实现和配置复杂，需要用户改登录设置 |

## 决定

使用 `CGEvent` 的 unicode 字符串模式输入密码（支持非 ASCII 密码），先按一次 Shift 唤出密码框。登录密码保存在本机钥匙串，仅本 App 可访问。

## 代价

- 依赖辅助功能权限；系统更新可能改变锁屏界面行为，每次大版本升级需要回归测试。
- 密码更改后需要用户在 App 内重新输入（M2 检测解锁失败并提示）。
