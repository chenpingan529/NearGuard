# 0004 核心逻辑放进纯 Swift 包 GuardKit

- 状态：已接受
- 日期：2026-09-23

## 背景

BLE、锁屏、摄像头、推送都只能在真机上测试，反馈慢且难以覆盖边界情况。

## 决定

- 所有判断逻辑（协议、加密校验、测距判定、警戒状态机）放在 `Shared/GuardKit`，不引用任何系统 UI / 硬件框架。
- 状态机采用「输入事件 + 当前时间 → 输出动作」的形式，时间和 ID 生成器通过参数注入。
- App 层只做系统事件与 GuardKit 之间的翻译。

## 代价

- App 层需要多写一层适配代码。
- 系统行为本身（例如锁屏通知的时序）仍需真机测试覆盖。
