# 测试策略

## 1. 分层

| 层级 | 范围 | 工具 | 何时运行 |
|---|---|---|---|
| 单元测试 | GuardKit 全部逻辑 | Swift Testing，`swift test` | 每次提交，CI 自动 |
| 构建检查 | 两端 App 可编译、无警告 | `xcodebuild` | 每次提交，CI 自动 |
| 格式检查 | `.swift-format` | `swift-format lint --strict` | 每次提交，CI 自动 |
| 真机测试 | BLE、锁屏、摄像头、推送 | 下方清单，手工执行 | 每个里程碑结束、发版前 |

一条命令跑完前三项：`scripts/test.sh`。

## 2. 单元测试覆盖要求

| 模块 | 必须覆盖 |
|---|---|
| 签名 / 封包 | 正常往返、换钥失败、篡改失败、跨类型挪用失败、畸形数据 |
| 配对 | 正常流程、无配对码、替换公钥、伪造回执、过期二维码 |
| 防重放 | 一次性核销、过期、未签发、时间窗口、容量上限 |
| 测距 | 无效值、尖刺、跟随、回差区、驻留时间、超时、断开 |
| 警戒状态机 | 每条规则至少一个正例和一个反例；时间边界（刚好到期 / 差一点） |
| 定时警戒 | 当天、跨夜、跨周、边界分钟、未启用 |

状态机测试使用 `Harness`（见 `GuardPolicyTests.swift`）：以相对秒数驱动时间，ID 用固定序列，断言完整的动作列表。

## 3. 真机测试清单

测试设备：Mac（macOS 26.x）+ iPhone 12 Pro（iOS 26.x）。每次记录系统版本和结果。

### M1：BLE 配对与测距

- [ ] 扫码配对成功；过期二维码、重复扫码被拒绝
- [ ] 前台：走近 / 走远，菜单栏距离状态正确变化，记录各距离的 RSSI
- [ ] iPhone 锁屏、App 在后台 10 分钟后，走远再走回，Mac 能重新收到报告
- [ ] iPhone 重启后未打开 App，能否恢复连接（记录结果）
- [ ] 关闭 / 打开 Mac 蓝牙后能自动恢复
- [ ] 电量：iPhone 后台 1 小时耗电

### M2：解锁、锁屏、警戒、抓拍

- [ ] 手机靠近自动解锁；手机离开自动锁屏
- [ ] 手机在身边手动锁屏，不会被立即解锁
- [ ] 离开满 30 秒进入警戒，回来解除
- [ ] 警戒中锁屏动鼠标 / 敲键盘 / 合盖再开 / 插 USB / 唤醒屏幕，均抓拍一次
- [ ] 按锁屏快捷键不会误抓拍（宽限期）
- [ ] 观察期内 Touch ID 自证 → 不报警、照片删除
- [ ] 定时警戒时间段内手机靠近不自动解锁
- [ ] 睡眠唤醒后各功能恢复

### M3：CloudKit 与远程处理

- [ ] iPhone 使用蜂窝网络，报警推送在 10 秒内到达，照片可查看
- [ ] 通知按钮 [立即锁定]：Mac 锁屏并补拍
- [ ] 通知按钮 [是我本人]：事件标记为已确认
- [ ] 同一指令重放被拒绝（用调试菜单重发旧记录）
- [ ] Mac 离线期间的指令超过 120 秒后被拒绝

### M4：回归

- [ ] 以上全部
- [ ] 开机自启动
- [ ] 公证后的正式包在干净的 Mac 上首次运行，权限引导正确
