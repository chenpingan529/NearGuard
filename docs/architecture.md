## 1. 组件

```
┌──────────────────────── Shared/GuardKit（纯逻辑，单元测试覆盖）────────────────────────┐

│ Crypto     Signer（软件 / 安全芯片）· 验签 · 配对证明 · 挑战簿 · 防重放                     │
│ Proximity  RSSIFilter（中位数 + 指数平滑）· ProximityClassifier（回差 + 驻留时间）        │
│ Policy     GuardPolicy 警戒状态机 · GuardSchedule 定时警戒                               │
│ Cloud      CloudKit 记录结构                                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘
        ▲                                                    ▲

│ ActivityDetector 锁屏时的输入/合盖/USB/唤醒   │   │ SecureEnclaveKey 安全芯片私钥            │

│ CloudChannel    上报事件、接收指令            │   │ CloudChannel    接收事件、发送指令         │
```

App 层只做适配：把系统事件翻译成 `GuardEvent`，执行 `GuardPolicy` 返回的 `GuardAction`。

## 2. 距离判定

1. iPhone 连接 Mac 后周期性读取信号强度（RSSI），经 `RSSIFilter` 平滑。
2. iPhone 读取 Mac 的挑战（一次性随机数），把平滑后的 RSSI 和随机数一起签名，写回 Mac。
3. Mac 用配对时保存的公钥验签、核销随机数，再把 RSSI 交给 `ProximityClassifier`。
4. `ProximityClassifier` 输出 `near` / `far` / `absent`：

| 参数 | 默认值 | 作用 |
|---|---|---|
| `nearThreshold` | -62 dBm | 大于等于算靠近 |
| `farThreshold` | -75 dBm | 小于等于算离开；两者之间为回差区，保持原状态 |
| `nearDwell` | 1.5 s | 靠近要持续这么久才生效 |
| `farDwell` | 4 s | 离开要持续这么久才生效 |
| `absentTimeout` | 10 s | 这么久没有有效报告算不在；连接断开立即算不在 |

阈值需要在 M1 真机实测后校准，最终会在设置里提供「在当前位置校准」。

## 3. 警戒状态机（`GuardPolicy`）

输入：`GuardEvent`（距离变化、锁屏/解锁、操作、Touch ID 自证、远程指令、定时器）。
输出：`GuardAction`（解锁、锁屏、抓拍、上报、撤销、警戒状态变化）。

### 警戒来源（可叠加）

| 来源 | 进入 | 退出 | 自动解锁 |
|---|---|---|---|
| `away` | 手机不在身边 ≥ 30 秒 | 手机回到身边 | 手机回来即解除，可解锁 |
| `schedule` | 进入设定时间段 | 离开时间段 | **禁用** |
| `manual` | 用户手动开启 | 用户手动关闭 | **禁用** |

### 事件处理

```
                    警戒中 + 已锁屏 + 超过锁屏宽限期(3s) + 有人操作
                    或 警戒中 + 屏幕被解锁
 ┌────────┐  ─────────────────────────────────────────────▶ ┌──────────────────┐
 │  空闲   │                  抓拍                          │ 观察期（20 秒）     │
 └────────┘ ◀───────────────────────────────────────────── └──────────────────┘
      ▲        Touch ID 自证 / 手机回到身边 / 手机确认本人：撤销，删除照片   │
      │                                                                 │ 到期
      │                          上报（带照片）→ 冷却 60 秒                 │
      └─────────────────────────────────────────────────────────────────┘
```

要点：

- **锁屏宽限期**：原型发现按锁屏快捷键本身会被当成「有人操作」，所以锁屏后 3 秒内的输入忽略。
- **观察期内只拍一张**因操作触发的照片；观察期内屏幕被解锁会再补拍一张（拍到解锁的人）。
- **手机回到身边即撤销**：自动解锁本身就以「手机在场 = 本人在场」为信任前提，这里保持一致。
- **手动锁屏防反弹**：手机在身边时手动锁屏，需等手机离开一次后才恢复自动解锁。
- **远程锁定**：锁屏 + 抓拍；如果有观察中的事件，立即上报，不再等观察期。

## 4. 平台限制与对策

| 限制 | 对策 |
|---|---|
| iOS 后台 App 的 BLE 广播对其他设备基本不可见 | iPhone 做中心设备主动连接 Mac（见 ADR 0001） |
| iOS 后台定时器会被挂起 | 连接期间靠 BLE 回调驱动；断开后发起挂起连接，靠近时由系统唤醒 |
| 锁屏状态无法用公开 API 解锁 | 模拟键盘输入密码（原型已验证 macOS 26.5 可行，见 ADR 0003） |
| 模拟输入需要辅助功能权限，沙盒 App 无法获得 | Mac App 不走沙盒，Developer ID 签名 + 公证分发（见 ADR 0002） |
